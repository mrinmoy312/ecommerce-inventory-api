
# E-Commerce Inventory Management API

A backend inventory management system designed for an
e-commerce platform.

## About the Project

This project aims to build a RESTful API that manages
products, stock levels, inventory operations and customer
orders.

The system will use PostgreSQL for persistent data storage
and Redis for caching frequently accessed information.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Redis
- Docker
- Pytest
- Git and GitHub

## Planned Features

- Product management
- Inventory tracking
- Stock addition and deduction
- Order management
- Prevention of overselling
- Inventory transaction history
- Redis caching
- User authentication and authorization
- API testing
- Docker-based deployment

## Project Status

Currently in development.

## Learning Goal

Build a production-oriented backend application while
learning Python, backend development, databases,
caching, testing and deployment.
